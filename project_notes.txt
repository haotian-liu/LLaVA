======================
ENVIERMENT SETUP
======================
1. move  .tar.gz file to your habrok from your comp
scp llava_dev_amd64.tar.gz s4723708@gpu1.hb.hpc.rug.nl:/scratch/s4723708/

2. make the container on habrok
module load apptainer
cd /scratch/$USER
gunzip llava_dev_amd64.tar.gz
apptainer build llava_dev.sif docker-archive://llava_dev_amd64.tar

3. (optinal) you can work within this container
apptainer shell llava_dev.sif
* to leav the container simply typing: exit
